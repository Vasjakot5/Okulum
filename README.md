## О проекте
Okulum - История России под микроскопом - это исторический сайт, с помощью которого пользователь может наглядно изучить историю Росии через изменение карты. Сайт предназначен для студентов, преподавателе и всех интересующихся, кто хочет визуально проследить, как менялись границы, города и ключевые объекты в разные периоды от Российской Империи до современной России.

## Технологии
- PHP 8.1
- Yii2 Framework
- MySQL 8.0
- Bootstrap 5
- JavaScript

## Основные функции
- Интерактивная карта с городами
- Каталог статей (события, люди, техника, оружие, одежда и т.д.)
- Система комментариев
- Обсуждения
- Личный кабинет пользователя
- Админ-панель
- Модерация и система банов и автобанов за нецензурную лексику(смотрите в components/ModerationService.php)

## Что выполняет данный сайт?
Этот сайт выполняет функцию интерактивного образовательного портала, позволяющего пользователям наглядно изучать историю России через динамическую карту с изменяемыми границами, а также взаимодействовать с контентом через каталог статей, обсуждения, личный кабинет и систему модерации.

## Инструкция по запуску проекта
1. Войдите в папку config файл db.php.
   
1.1. Измените имя пользователя и пароль или оставьте так + по желанию можете изменить название базы данных.

2. Откройте PhpMyAdmin или другое веб-приложение для работы с базами данных и создайте там свою БД.

2.2 Выполните миграции.
   
2.2 Затем импортируйте в свою БД файл База данных.sql(который расположен в корне этого проекта), который находится в корне проекта.

3. Закиньте проект на хостинг(или используйте локальный сервер по типу: OpenServer или XAMPP) и запустите его.

4. Проверьте, чтобы всё было подключенно и введены правильные данные
